## [0.32.0] — 2026-11-28

First general-availability (GA) release targeting **Apple Pkl `0.32.0`** across all 4 distribution channels (GitHub Releases, npm `@openedges/pkl-wasm` & `@openedges/pkl-napi`, crates.io `pkl-lang` + 7 workspace crates, and Homebrew `openedges/homebrew-tap`).

### Breaking Changes (Pre-GA Public API Cleanup)

- **Rust `FromPklValue` (`crates/pkl` [`pkl-lang`])**: Replaced `impl FromPklValue for Vec<u8>` (which collided with blanket `Vec<T>`) with the explicit newtype **`PklBytes(pub Vec<u8>)`** for Pkl `Bytes` values, and added `FromPklValue` implementations for `i8`, `u8`, `i16`, `u16`, `u32`, `isize`, `f32` (rejecting non-finite overflow), `PklDuration`, and `PklDataSize`.
- **JS/Wasm Testing Subpath & Cross-Package API Unification (`@openedges/pkl-wasm`, `@openedges/pkl-napi`)**: Moved internal benchmark/roundtrip helpers (`roundtripValue`, `roundtripInteger`, `roundtripBytes`, `roundtripString`, `measureConversion`) out of the primary `"."` export into the dedicated **`"./testing"`** subpath export (`@openedges/pkl-wasm/testing`, `@openedges/pkl-napi/testing`), and unified `PklObject` (`toJSON()`, empty collection identity, frozen getter guard, strict setter validation), `ModuleSource.modulePath` normalization, `PClassSchema`/`TypeAliasSchema` (`info` + `moduleUri`), `TestResults`/`TestSectionResults`/`TestResult`, `ReplSession` (`eval({ evalDefinitions })`, `cancel()`, non-closing timeout/cancel reuse), `decodePklBinary(bytes, { strict })`, `analyzeImportGraph` (`ModuleSource[]` + security enforcement), and `measureConversion` dual-signature telemetry across both packages.
- **SemVer Forward Compatibility & Crate Hygiene (`crates/pkl`, `crates/pkl-host-native`)**: Marked public re-exported enums and option structs `#[non_exhaustive]`, hid internal `Project::dependencies_manager`, normalized `ModuleSource::module_path`, copied `evaluator_settings` in `AnalyzerBuilder::with_project`, exposed `ImportNode` cleanly from `pkl::analyzer`, and moved the internal M4 test harness `pkl_m4_cli` from `crates/pkl-host-native/src/bin/` into `crates/pkl-host-native/examples/` so `pkl-host-native` publishes cleanly as a library crate without internal harness binaries.

### Security

- **Filesystem, Symlink, Custom Security Manager & `rootDir` Confinement (`crates/pkl-host-native`, `crates/pkl-runtime`, `crates/pkl-cli`, `crates/pkl-doc`, `crates/pkl`, `crates/pkl-napi`, `packages/pkl-wasm`)**: Hardened symlink-aware canonicalization (`try_resolve_canonical_or_ancestor`, fail-closed at >40 hops), preserved literal `\` on POSIX paths in both Rust `normalize_lexical_path` and Wasm `VirtualFileSystem` (`normalizeVfsPath`, blocking `%5c` / backslash `--root-dir` escapes), enforced `allowedResources` and `http:`/`https:`-only `packageZipUrl` checks on Wasm `package://` fetches matching Apple Pkl `PackageResolvers.java`, enforced fail-closed handling when combining `projectDir` with a custom `securityManager` in `@openedges/pkl-napi`, enforced `allowedModules` and cache refresh when reading expected `.pcf` files in `evaluate_test`, enforced `CustomSecurityChecker` across `env:`/`prop:` globs, `pkl:*` standard library modules, canonicalized `file:`/`jar:file:` URIs, and `StandardSecurityManager`/`JsSecurityAdapter` fallbacks, enforced `O_NOFOLLOW` / Windows `FILE_FLAG_OPEN_REPARSE_POINT` on reads and writes (`open_file_nofollow`, `write_file_nofollow`, `append_file_nofollow`) including CLI/test/doc writers, fixed dangling-symlink overwrite escapes in `pkl test --overwrite` and double-placeholder CLI output paths, escaped all raw HTML (`Block::HtmlBlock` / `Inline::HtmlInline`) in `pkldoc` Markdown output in addition to inline-script JSON escaping and `href`/`src` URL scheme sanitization (`javascript:`, `vbscript:`, `data:`, scheme-relative `//`, and metadata URLs), and blocked `http:`/`https:` imports in `PklSettings::load`.
- **HTTP, TLS, MVS & Archive Limits (`crates/pkl-host-native`, `crates/pkl-runtime`)**: Rejected CRLF/whitespace/control characters in HTTP URIs, `+`-prefixed `Content-Length` headers, and query/fragment suffixes in rewrite rules, hardened `NoProxyRule` for trailing dots and IPv4-mapped IPv6, stripped cleartext `userinfo` from proxy absolute-form targets (RFC 9110 §4.2.4), enforced bounded header lines (`64 KiB`), header counts, and response bodies (`256 MiB`) with `try_reserve`, verified pinned SHA-256 checksums across revisit paths in MVS dependency resolution, isolated per-evaluation timeout cancellation with monotonic deadlines (`ScopedEvalCancel::push_with_deadline`), and hardened ZIP extraction against macOS `OS == 19` symlink entries, excessive path depth (`MAX_ZIP_PATH_DEPTH`), 0-payload O(N²) directory-metadata bombs (`MAX_ZIP_DIR_METADATA_BYTES`), and zip bombs.
- **Typed Security Classification & IPC Bounds (`crates/pkl-runtime`, `crates/pkl-server`, `crates/pkl-wasm`, `crates/pkl-napi`)**: Replaced fragile error-message substring heuristics with a typed `security_manager_exception` error bit (`RuntimeError::is_security_error()`), added frame-size caps and strict MessagePack validation with `EINTR` retry across `pkl server` (`0x20–0x25`) and external reader subprocesses (`0x26–0x32`), prevented late callback responses after `CloseEvaluator` or timeout from crashing unrelated evaluators on the same `pkl server` connection (and ensured cancelled-ID eviction preserves live callback IDs), and prevented premature `SIGKILL` of idle external readers during graceful N-API evaluator close (`0x32`).

### Performance

- **V8 Liftoff Wasm Outlining, Compact Unicode Name Tables & `wasm-opt` RSS Guard (`crates/pkl-runtime`, `crates/pkl-wasm`, `packages/pkl-wasm/scripts/build.mjs`)**: Annotated cold single-caller VM helpers with `#[cfg_attr(target_arch = "wasm32", inline(never))]`, split oversized instruction dispatchers (`182.8 KiB` → `34.8 KiB` max Wasm function size), packed the `1.46 MB` Unicode 15.0.0 `\N{...}` character-name tables at build time via zero-dependency front-coding + RLE (`354 KB`, **`-1.11 MB` raw** across `.wasm`, `pkl`, `pkldoc`, and `.node` binaries), and made external `wasm-opt` strictly opt-in (`--wasm-opt`) after empirical 5-way Binaryen 133 A/B benchmarking showed `wasm-opt -Os/-Oz` re-inlines outlined cold helpers and doubles V8 peak RSS (`173.4 → 347.8–350.6 MiB`). This yields `pkl_wasm_bg.wasm` at **`5,698,133 B` raw / `1,960,812 B` (`1.870 MiB`) gzip-9** (25.2% under the `2.50 MiB` budget), **`4.81 MiB`** (`5,046,272 B`) linear memory on `typed-conversion`, and **`wasm-node:typed-conversion` at `8.17 us` (`0.254x–0.257x` time, `0.970x` RSS in `m7-js` / `0.968x` in `m7-bench`)**.
- **Warm-Query, Lazy Cancel Guard & Pure-Host File Import Fast Paths (`crates/pkl-runtime`, `crates/pkl-host-native`, `crates/pkl`)**: Added lazy `ScopedEvalCancel` pushing (deferred until host I/O when no timeout is active), zero-allocation `&str` warm-cache queries (`SourceSession::try_start_warm_evaluation_str`), and inline relative `file:` URI/key resolution for pure standard hosts — maintaining `import-graph:persistent` at **`0.894x`** vs. archived M0 GraalVM 25.0.1 (`0.97 us`, `0.858x` vs. Temurin 21) and `import-graph:fresh-evaluator` at **`0.879x`** vs. archived M0 GraalVM 25.0.1 (`198.97 us`, `0.847x` vs. Temurin 21).
- **JS/Wasm Columnar & `PklObject` Fast Paths (`packages/pkl-wasm`, `packages/pkl-napi`)**: Cached pre-sliced string/BigInt columnar arrays in `viewCache`, made `PklObject` `entries`/`elements` lazy behind symbols, skipped guaranteed-miss `repl:text` fast-probe FFI copies in `@openedges/pkl-napi`, and allowed one cold-slot retry in `IntSeqNext` `FastIntBlock` bulk loops — accelerating browser `typed-conversion` up to **5.0x faster than Java** (WebKit `0.201x`, Chromium `0.254x`, Firefox `0.425x`) and keeping `stdlib-collections:fresh-evaluator` at **`103.76 us` (`0.378x` time / `0.060x` RSS)**.
- **`pkldoc` Output Confinement Fast Path (`crates/pkl-doc`)**: Replaced redundant per-file ancestor `realpath` walks in `write_files_parallel_under` and `ensure_path_under_output_dir` with once-per-unique-directory canonicalization plus `O_NOFOLLOW` writes, maintaining `pkldoc-single-package:cold-cli` at **`0.835x` time / `0.528x` RSS** against Official Apple Pkl `0.32.0` `native-image`.
