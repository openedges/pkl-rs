## Summary of M5 Implementation Tracks

### 1. Shared Runtime M5 Extensions (`crates/pkl-runtime`, `crates/pkl-host-native`)
- **Schema Introspection (`crates/pkl-runtime/src/schema.rs`, `vm/schema.rs`)**: Implements cooperative `SchemaExtractor` exposing module metadata, doc comments, annotations, classes, type aliases, properties, methods, supertypes, and `PType` representations used by `pkldoc`, `pkl-repl`, and the public Rust API (`crates/pkl`).
- **REPL Core (`crates/pkl-runtime/src/repl/`)**: Implements pure-Wasm stateful `ReplSession` (`ReplRequest::{Eval, Load, Completion, Reset}` with `force_results: bool` on `Eval`, `ReplResponse`, `:examples`, `:force`, `:load`, `:reset`, `:help`, `:quit`, lexical scope persistence, incomplete-input detection, and identifier/member completion).
- **Server Protocol Core (`crates/pkl-runtime/src/server/`)**: Implements pure-Wasm `0x20–0x25` (`CreateEvaluatorRequest/Response`, `CloseEvaluator`, `EvaluateRequest/Response`, `LogMessage`) plus `0x26–0x32` client/external reader callback messages (`ReadResource`, `ReadModule`, `ListResources`, `ListModules`, `CloseExternalProcess`), MessagePack framing, evaluator registry, request concurrency, cancellation, and structured log/error transport.
- **Command Runner, ANSI Diagnostics, Power Assertions, and Pkl Binary (`crates/pkl-runtime/src/{evaluation/command.rs,diagnostic/ansi.rs,diagnostic/frames.rs,power_assertions.rs,vm/pkl_binary_render.rs}`)**: Adds `pkl:Command` evaluation support (`pkl run`), ANSI color diagnostic rendering (`render_ansi`, `--color`), power-assertion highlighting aligned with Pkl 0.32.0 CLI output, and shared `EncodePklBinary` / `PklBinary` value encoding across `pkl-server` and `crates/pkl`.
- **Native Host Extensions (`crates/pkl-host-native/src/{driver.rs,lib.rs}`)**: Adds `NativeHostExtensions` supporting custom Rust module/resource readers, custom loggers, custom stack-frame transformers, and server-mode client reader bridges without `thread_local!` state or Java fallback.

### 2. Public Rust Evaluator API (`crates/pkl`, `crates/pkl/examples/pkl_m5_api_probe.rs`)
- **Ergonomic Public API (`crates/pkl/src/`)**: Provides `EvaluatorBuilder` (including `EvaluatorBuilder::preconfigured()`), `Evaluator`, `ModuleSource`, `PklValue`, typed decoding, `ModuleReader` / `ResourceReader` SPI traits, `Logger`, `StackFrameTransformer`, `evaluate_output_text`, `evaluate_output_bytes`, `evaluate_output_files`, `evaluate_output_value`, `evaluate_expression`, `evaluate_schema`, and deterministic `close()` lifecycle cleanup.
- **Differential API Probe (`crates/pkl/examples/pkl_m5_api_probe.rs`)**: Paired 1:1 with `tools/java/M5ApiOracleProbe.java` across all 13 `m5:api:*` scenarios (core text/bytes/files/value/expression/schema outputs, custom module & resource readers, custom logger, stack-frame transformer, project settings, timeout cancellation, and close/post-close error behavior).

### 3. Product `pkl` CLI (`crates/pkl-cli`, binary `pkl`)
- **Full Subcommand & Option Parity (`crates/pkl-cli/src/`)**: Implements the unified product `pkl` binary covering all M5-scoped CLI commands (`eval`, `repl`, `server`, `test`, `project resolve`, `project package`, `download-package`, `analyze imports`, `format`, `run`, `shell-completion`, `--help`, `--version`), 26 new M5 CLI options alongside M3/M4 options, exact `--help` text parity, honest native-flavor `--version` (`Pkl 0.32.0 (<os>, native)`), `--color`, `--format`, `--multiple-file-output-path`, `--expression`, `stdlib/doc-package-info.pkl` evaluation, `pkl test` (`spec` and `minimal` reporters, `--junit-reports`, `--overwrite`), `pkl run` (`pkl:Command`), and `shell-completion` (`bash`, `zsh`, `fish`).

### 4. Interactive & Pipe REPL (`crates/pkl-repl`)
- **REPL Driver & Line Editor (`crates/pkl-repl/src/`)**: Bridges `pkl_runtime::repl::ReplSession` to native interactive PTY sessions and non-interactive stdin pipes (`pkl repl`), preserving exact prompt/banner formatting, multi-line continuations, `:load`/`:force`/`:reset`/`:examples`/`:help`/`:quit` commands, evaluator flags (`-e`, `-p`, `--working-dir`, `--allowed-modules`, `--allowed-resources`), and EOF/error exit codes across all 12 `m5:repl:*` cases.

### 5. Evaluator Server (`crates/pkl-server`)
- **Server Runtime (`crates/pkl-server/src/`)**: Implements `pkl server` stdin/stdout MessagePack RPC over `pkl_runtime::server` (`0x20–0x32`), handling `CreateEvaluator` (inline/project settings, HTTP proxy/rewrites/CA, client module/resource readers, external readers, `color`, `timeout`), concurrent `Evaluate` requests across multiple evaluator IDs, `LogMessage` notifications, `CloseEvaluator`, malformed/unknown-evaluator error responses, and clean EOF shutdown across all 22 `m5:server:*` cases.
