## Implementation and evidence scope

A type source section owns immutable text, a span and a source-node identity. Substitution and declared-type resolution retain that section. Diagnostic equality compares source values, while union mismatch grouping explicitly tests node identity. External argument sections take precedence; a primary constraint may retain the URI supplied by its runtime block metadata without adopting the foreign value body's logical owner.

Shared type nodes cache whether substitution is required; both constructors inspect structural children and constraint argument maps. Native controls cover repeated lexical substitution and parameterized constraint arguments. This is invariant hardening: no pre-existing authored Java failure was established for the cached flag. Direct `unknown` uses the Java dynamic parent, whereas an alias to `unknown` retains its distinct inferred-parent behavior.

Entry numbering belongs to the object scope. Literal labels follow Java AST construction, including selected parenthesized, negative, Duration/DataSize and nullable-unit keys; this is not general constant folding. A scratch compiler visits ordinary members before a generator and retains entry counters. Its Program metadata/map copying remains a performance cost to measure.
