# 최종 유한 증거 복사

1. root가 selector05의 selection02와 새 archive pack/readback 종료·회수를 확인한다. 실제 pin만 mapping에 넣고 draft/terminal 상태를 실제에 맞춘다.
2. README/archive/index/integrity/source audit/pack report와 post-plan helper·review·config·guard·실패 영수증을 정확한 유한 표로 지정한다. 기존 frozen archive plan에는 추가하지 않는다.
3. HEAD·floor 1,216MiB·reserve 128MiB 및 실제 새 복사량을 확인한 뒤 source/destination bytes·SHA·mode를 검증하고 exclusive copy한다. README만 기존 동일 pin을 허용한다. 실패 시 남은 부분 파일을 보존한다.
4. 모든 복사 전후 검증 후 publication.json을 생성한다. 실제 commit/push는 별도로 기록하며 전체 M2·API·플랫폼·성능 완료로 바꾸지 않는다.

현재 source 준비만 했으며 실제 복사·archive 읽기·runtime/cache 조회·Git 변경은 수행하지 않았다.
